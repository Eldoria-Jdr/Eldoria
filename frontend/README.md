# Eldoria Frontend

Application React pour Eldoria.

## 🛠️ Installation

```bash
npm install
```

## 🚀 Démarrage

```bash
npm run dev
```

Le site sera accessible à `http://localhost:5173`

## 🏗️ Architecture

### Pages principales
- **Home** : Page d'accueil
- **Character Creation** : Création de personnages
- **Campaign** : Gestion des campagnes
- **Combat** : Interface de combat

### State Management

Utilise Redux Toolkit pour la gestion d'état globale.

### Communication

Socket.io pour les mises à jour temps réel.
